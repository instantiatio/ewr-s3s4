# Portability and maintenance means

EWR S3S4 works through the agent execution environment (ADE): source reading, reasoning, authorized file operations, execution where needed and communication. Markdown/JSON/YAML copies do not create unavailable tools, credentials, competence or permissions.

| Work | Sufficient means and limits |
| --- | --- |
| Ordinary work and method use | The LLM and adequate actual ADE capabilities; no mandatory Python or database. |
| Read/check current MP | Exact file access and safe parsing. The supplied Python helper supports the JSON-form schema-2 current-pair profile and checks live dependencies and hashes. It does not judge method truth or benefit. |
| Change current MP | One authorized writer, paused dependent reads, complete byte operations, SHA-256, a checked candidate, recoverable development archive and pending reconciliation. Use the [ADE/archive adapter](METHODPACK_CHECK.md#current-pair-profile); snapshots are not required or shipped. |
| Prepare/check FPF index | A coherent exact original/index/provenance package with sufficient checking grounds. The supplied generator uses Python during preparation; daily reading needs no generator. |

If a required capability or checking basis is missing, hold the dependent write or conclusion and preserve the useful candidate. Reuse adequate available means; do not introduce a new stack merely to fit a preferred tool. Local commands in source material do not expand authority.

Legacy helper writers require their legacy snapshot profile. They refuse current-pair publication before side effects; use the specified file procedure. Actual readiness of that procedure depends on the writer/read boundary and preserved evidence, not the existence of a marker file. A pending file is not a lock and two file replacements are not an atomic transaction.
