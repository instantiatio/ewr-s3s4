## Description and source use

The schema-2 index uses project-relative paths and `pack.storage_profile: current-pair`. It records actual bodies/anchors/ranges, the current book and body hashes, selection conditions, relations, status and limits. Candidate descriptions and observations retain their actual evidence basis. A thematic group is not formal composition.

Current general FPF lookup uses the one installed original and structural index. The index's current FPF candidate routes locate the selected pattern; read the original conditions for the task before applying it. Historical FPF grounds retain their source editions under `historical_FPF_basis`. They do not assert that an old local file is present or that the source has been requalified. Author-family and exact contribution lookup continue through `basis[].source_refs` and `source_contributions`.

Authorship, terms and exact source provenance are in [ORIGINS.json](../ORIGINS.json) and [source notices](METHOD_SOURCE_NOTICES.md). The historical author source is not automatically a runtime input. A task requiring its exact content needs sufficient accessible grounds under the source policy.

## Maintenance

The [current-pair installation adapter](METHODPACK_CHECK.md#current-pair-profile) governs the storage/publication operations of baseline IE-M003 and IE-M004. Maintain one current pair; preserve prior states in verified development archives or immutable repository history outside the clean package. Do not ship or recreate `methods/snapshots` for this profile. Before mutation, establish one writer, exact before/after, a checked candidate, a recoverable archive and a pending/reconciliation record. A failed material check holds publication with every implementation.

The supplied helper checks the pair without writing. Current-pair updates use the documented ADE file procedure. Daily work and ordinary method use do not require Python. Actual suitability is assessed for the receiving task; this restoration adds no empirical efficacy claim.
